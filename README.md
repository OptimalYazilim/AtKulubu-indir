# At Kulübü — indirme

Oyunun test paketleri. Kaynak kod bu depoda değil.

İndirmek için sağdaki **Releases** bölümüne gidin ve son sürümü açın.

- Mac: `AtKulubu_v0.6_Mac.zip` — açtıktan sonra uygulamaya sağ tık > Aç (imzasız uygulama).
- Windows: `AtKulubu_v0.6_Windows.zip` — klasörü açıp `AtKulubu.exe`'yi çalıştırın; SmartScreen çıkarsa "Ek bilgi" > "Yine de çalıştır".
